GOOD TO KNOW

Frequently asked questions.

Do I need a license?

Yes. PagePilot Pro uses a separate PPRO- license key and online verification. A Pro key does not activate PagePilot Classic.

Does the installer include my browser profiles or Facebook sessions?

No. Official releases do not include customer profiles, cookies, saved sessions, local databases or license keys. Your local application data is stored separately from the Program Files installation.

Does PagePilot Pro install its required browser runtime?

The Windows installer bundles the application's required Electron runtime. You do not need to install the packaged runtime separately.

How do updates work?

The Updates tab checks signed PagePilot Pro version information. For newer releases it can download an official installer, verify its size and SHA-256 checksum, and launch Windows Setup after your approval. Finish active jobs and close Browser Wall before installing.

What happens to my license and data during upgrades?

The installer uses a separate Program Files directory. Browser profiles, license cache and the local database live in local application data and are designed to be preserved across upgrades. Keep backups of important data.

Can I use PagePilot Pro with any Facebook account?

Use only accounts and Pages you own or are authorized to manage. Follow applicable Facebook and Meta policies. Login, CAPTCHA and security challenges may require manual action.
